This repo is for storing past, live, and WIP localizations for the stellaris mod [Phrolova Beyond](https://steamcommunity.com/sharedfiles/filedetails/?id=3834610699).
The mod's original language is Chinese Simplified.
Currently planned translations are English and Japanese.

Translations are done using Claude with wuwa and stellaris context, then edited by humans with a focus on lore/terminology accuracy.
